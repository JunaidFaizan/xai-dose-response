## What is in the release

| File | Content |
|---|---|
| `xai-dose-response_code_<sha>.zip` | All tracked files of the repository at that revision: training, scoring, analysis and paper-build code, tests, pre-registration documents, Kaggle notebooks. |
| `xai-dose-response_results_<sha>.zip` | `results/dose_response/`: per-model result files (`per_model/`, including the `*_road.csv` files), analysis tables (CSV), figures and `summary.md`. |
| `xai-dose-response_checkpoints_partNofM.zip` | `checkpoint/dose/`: 297 trained models (`*.pt`, PyTorch state dicts) and their `*_metrics.json` files. The 293 models of the study plus 4 pilot models that are not pooled in any analysis. |

Folders inside the code zip: `xai/` (library: data, models, metrics, ROAD, statistics, analysis),
`dose_response.py` (train, evaluate, placebo, behaviour, road, analyze), `paper/` (manuscript builder),
`tests/`, `docs/` (pre-registration, amendments, submission files), `kaggle/` (notebook generator and
instructions), `results/` (the committed analysis outputs).

## How to rerun

Python 3.12. Pinned packages are in `requirements.txt` (torch 2.14.0, torchvision 0.29.0, captum 0.9.0,
medmnist 3.0.2, numpy, scipy, pandas, matplotlib, pillow). From the root of the unzipped code:

```
python -m venv .venv
.venv\Scripts\python.exe -m pip install -r requirements.txt    # Windows; use .venv/bin/python on Linux
.venv\Scripts\python.exe -m unittest discover -s tests -t .     # unit tests
```

Reproduce the analysis and the paper from the released results without any training: unzip the results zip over the
code folder (so that `results/dose_response/` exists), then

```
.venv\Scripts\python.exe dose_response.py analyze              # all analysis tables from the per-model files
.venv\Scripts\python.exe paper\build_paper.py --submission     # manuscript, supplement, highlights, figures
```

Retrain and rescore (long): `python dose_response.py all` trains, evaluates and scores the CPU-sized settings
(about 3 hours on a laptop CPU for the small settings); the ResNet-18 settings were trained on a Kaggle T4 GPU with the
notebooks in `kaggle/` (see `kaggle/README.md`; notebooks are generated by `kaggle/build_notebook.py`).
`python dose_response.py behaviour` and `python dose_response.py road` add the per-image behavioural labels and exact
ROAD scores. To score the released checkpoints, unzip the checkpoint parts so that `checkpoint/dose/*.pt` exists
and run `evaluate`, `placebo`, `behaviour` or `road` as above. Training is not bit-reproducible across hardware
(GPU versus CPU); the released per-model results are the ones reported in the paper.
